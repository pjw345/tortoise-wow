Extracts the actual party-kill admission action/class and actual gated packet
registration. Controlled raw 16-byte packets exercise killer/victim order,
truncated/wrong-opcode/non-creature input, packet cursor preservation, active
master/group/dead/strategy controls, normal-admission refusal/duplicates and
gather opt-in. Other variants retain their original bindings. Extraction checks
the native Unit::Kill wire order and gated trigger/action/strategy wiring.
PACKET_SOURCE selects the prior registration for a failing ZERO control.
Admission services and WorldPacket transport are controlled; existing native
admission/safety/skin regressions and actual-header compiles complement these
fixtures. Full native queue/trigger scheduler/world execution is not simulated.
