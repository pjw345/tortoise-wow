Executes the native Turtle result-name helper, the production formatter and the actual CanCastSpell/rejection guard extracted from CastCustomSpellAction::Execute. Controlled spell checks and text services cover unit/game-object overloads, rejection, missing result writes, known/unknown results, realm translations, missing/empty keys, and unchanged success/trade admission. It does not execute the entire target-selection or native Spell lifecycle. No Skinning requirement numbers are guessed from the generic failure code.
